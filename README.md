# VulnSync
**Automated Offensive Security Reporting Framework**

VulnSync is a specialized tool designed for Red Teamers and Penetration Testers to automate the tedious process of security reporting.

### Key Features
- **Nmap XML Parsing:** Automatically extracts open ports, services, and versions.
- **Vulnerability Mapping:** Stores findings in a structured database linked to specific projects.
- **Automated Word Reporting:** Generates professional .docx reports with tables and remediation strategies.

### Future Work
- Integration with Burp Suite and Nessus.
- CVSS v4.0 scoring automation.
